# TinyXML (Unofficial GitHub Mirror)

This repository is an **unofficial GitHub mirror** of the original TinyXML project.

The original TinyXML source code was obtained from the project's historical distribution archives hosted on SourceForge. This mirror exists solely for archival, dependency management, and reproducible build purposes.

## Original Project

Original TinyXML project:
- https://sourceforge.net/projects/tinyxml/

TinyXML was originally developed by Lee Thomason.
